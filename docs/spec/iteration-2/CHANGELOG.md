# Iteration 2 plan: changelog

Amendments to this folder and to ADRs 0013 to 0017 after three reviews of the plan (security, product, feasibility). Each finding was checked against the plan and the code before it was applied; the GoTrue, Postgres and Chrome sources the security findings rest on were read again where this file says so. No code was changed, nothing was committed and nothing was installed.
